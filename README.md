# Purvi's Learning Hub — Summer 2026

An 8-week, curiosity-driven curriculum for a 9th-grader entering Enloe Magnet High School with a goal of becoming a psychiatrist.

## What this is

A mobile-first web app with date-based week-gating, integrated weekly reflection (via Google Forms → Google Sheet), and 200+ curated free resources across math, biology, chemistry, psychology, entrepreneurship, and public speaking.

## Setup

See [SETUP_GUIDE.md](SETUP_GUIDE.md) for the full step-by-step guide.

## How it works

- The site lives at `https://rkarr2.github.io/purvi-hub/`
- Weeks unlock automatically every Monday from June 8, 2026 onward
- Identical experience on every device — no login, no sync
- Weekly reflections post to a private Google Sheet for parent review
